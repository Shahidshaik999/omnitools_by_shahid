#  OmniTools — Daily Digital Swiss-Army Knife

> **100% Client-Side, Private, and High-Performance Utility Hub for Everyday Digital Life.**  
> Convert PDFs to Word, optimize images, generate styled Wi-Fi QR codes, compare text/code diffs, create secure passwords, and more—all running directly in your browser with **zero server uploads**.

---

##  Key Features (19+ Built-in Utilities)

###  1. Document & PDF Studio
- **PDF to Word (`.docx`)**: Extract text, headings, and formatting into an editable Microsoft Word document.
- **Merge PDFs**: Combine multiple PDF files into one with reordering and deletion controls.
- **Split & Extract PDF**: Visual thumbnail page selector and custom range extractor.
- **Images to PDF**: Convert JPG, PNG, and WebP photos into multi-page PDFs with margins and orientation.
- **PDF to Images**: Export high-DPI PDF pages as PNG/JPG/WebP with one-click batch `.zip` download.
- **Sign & Annotate PDF**: Draw digital signatures (black, blue, red) and insert text directly onto PDF pages.

###  2. Media & Image Studio
- **Smart Image Compressor**: Live side-by-side split view comparing original vs. compressed image with instant size savings percentage.
- **Universal Format Converter**: Batch convert images between PNG, JPG, WebP, and BMP.
- **Document Photo Scan Filter**: Turn phone photos of paper receipts and documents into crisp black & white scans, with instant export to PDF.
- **Color & Palette Picker**: Extract dominant color palettes, hex codes, and copy ready-to-use CSS variables.

###  3. QR Code Studio
- **Custom QR Generator**: 100% offline QR engine for **URLs**, **Plain Text**, **Wi-Fi networks**, **vCards**, and **Emails** with custom colors and PNG/SVG export.
- **QR Code Scanner**: Decode QR codes from image uploads, clipboard pastes (`Ctrl + V`), or live webcam streams.

###  4. Security & Developer Suite
- **Password & Passphrase Generator**: Cryptographically secure random passwords or memorable Diceware passphrases with real-time bit entropy metering.
- **Text & Code Diff Checker**: Visual line-by-line diff comparison with color-coded additions (`+`) and deletions (`-`).
- **Unix Timestamp & Date Calculator**: Live ticking epoch clock, timestamp-to-human converter, and date duration calculator.
- **Markdown Scratchpad & Notes**: Distraction-free notepad with local storage auto-save and `.md` export.
- **Regex Playground**: Test regular expressions with match highlights, capture groups breakdown, and common presets.

###  5. Text & Data Utilities
- **Case Converter & Stats**: UPPERCASE, lowercase, Title Case, camelCase, snake_case, and reading time estimator.
- **JSON Studio**: Beautify (2 spaces), minify, auto-repair unquoted keys, and syntax validation.
- **Base64 & Hash Studio**: Base64/URL encoding and SHA-256 / SHA-512 cryptographic hashing.
- **Unit Converter**: Multi-category conversion (Length, Weight, Temperature, Digital Data, Area, Time).

##  100% Privacy-First Architecture
All file processing, image compression, PDF manipulation, and QR decoding occur **strictly inside your web browser** using HTML5 Canvas, WebAssembly, and local JavaScript. **Zero files are sent to remote servers.**

##  Getting Started

### Run Locally:
No complicated build steps or npm installations needed!

1. Clone this repository:
   ```bash
   git clone https://github.com/Shahidshaik999/omnitools_by_shahid.git
   ```
2. Open `index.html` in any modern web browser or serve it with any local static server:
   ```bash
   # Python
   python -m http.server 8080
   
   # Or Node.js npx serve
   npx serve .
   ```
3. Visit `http://localhost:8080` in your browser.
